# Charte graphique

## Ambiance visuelle

L'ambiance choisie est sobre, claire et professionnelle. Le site doit rappeler une studio d'architecture intérieure et de visualisation 3D.

## Couleurs

- Blanc cassé pour le fond principal.
- Blanc pour les cartes.
- Noir doux pour les textes.
- Gris chaud pour les textes secondaires.
- Taupe doré pour les accents, les boutons et les éléments actifs.

## Typographie

La typographie utilisée est Arial, Helvetica, sans-serif. Le choix est simple pour garder une bonne lisibilité et éviter une dépendance externe.

## Boutons

Les boutons ont des angles légèrement arrondis, une hauteur confortable et un contraste lisible. Le bouton principal utilise la couleur taupe foncée.

## Cartes

Les cartes servent à présenter les services, les projets et les avis. Elles utilisent un fond blanc, une bordure fine et une ombre légère.

## Mise en page

La mise en page utilise des grilles simples. Sur desktop, les cartes peuvent être affichées sur plusieurs colonnes. Sur mobile, les éléments passent sur une seule colonne.

## Choix graphiques

Les images existantes du projet sont utilisées pour donner une identité visuelle crédible au site. Les espaces blancs sont importants pour garder une lecture agréable.
